# Native WordPress Admin Classes Reference

## Buttons
- `.button` — default secondary
- `.button-primary` — main action (blue/theme color)
- `.button-secondary` — same as `.button`
- `.button-link` — looks like a link
- `.button-link-delete` — red link style
- Size modifiers: `.button-small`, `.button-large`, `.button-hero`

## Form elements
- `.form-table` — standard settings table
- `.regular-text`, `.small-text`, `.large-text`, `.code`
- `.description` — help text under fields
- `.form-required` — required field marker

## Tables
- `.widefat` — main admin table
- `.striped` — alternating rows
- `.fixed` — fixed layout
- Column helpers: `.column-primary`, `.check-column`, `.manage-column`

## Layout
- `.wrap` — main content wrapper
- `.wp-heading-inline` — page title next to actions
- `.page-title-action` — “Add New” style button next to title
- `.postbox` + `.postbox-header` + `.inside` — metabox style boxes
- `.meta-box-sortables` — sortable areas

## Notices
- `.notice.notice-success`
- `.notice.notice-error`
- `.notice.notice-warning`
- `.notice.notice-info`
- `.is-dismissible` — adds dismiss button

## Tabs
Native pattern uses `.nav-tab-wrapper` + `.nav-tab` + `.nav-tab-active`

## Color scheme helpers
- `.wp-ui-primary`
- `.wp-ui-text-primary`
- `.wp-ui-highlight`
- CSS variables: `--wp-admin-theme-color`, `--wp-admin-theme-color-darker-10`
